## 🗺️ Roadmap

### HTML — 2 Weeks
- [ ] **Week 1:** Structure & Text (Getting Started → Add Links)
  - Task: Build a static "About Me" page with proper `<head>`, headings, lists, and links
- [ ] **Week 2:** Media, Semantics & Data (Add Images → HTML Project)
  - Task: Rebuild "About Me" with semantic tags, image gallery, table, and a contact form

### CSS — 3 Weeks
- [ ] **Week 1:** Fundamentals (Start Here → List Styles)
  - Task: Style the "About Me" page — fonts, colors, box model, nav/list styling
- [ ] **Week 2:** Layout Systems (Mini Project → Images)
  - Task: Build a card-based portfolio grid using Flexbox and CSS Grid
- [ ] **Week 3:** Responsiveness & Polish (Media Queries → Final Project)
  - Task: Make the portfolio responsive, add animations + CSS variables, finish Final Project

### JavaScript — 4 Weeks
- [ ] **Week 1:** Core Syntax (Intro → Number Guessing Game)
  - Task: Rebuild Counter and Number Guessing Game from memory
- [ ] **Week 2:** Functions, Arrays & OOP Basics (Functions → Super keyword)
  - Task: Rebuild Dice Roller & Password Generator; practice `map`/`filter`/`reduce`
- [ ] **Week 3:** Advanced JS & Async (Getters/Setters → classList)
  - Task: Rebuild Digital Clock, Stopwatch, Calculator; build a small to-do list
- [ ] **Week 4:** DOM Projects & APIs (Rock Paper Scissors → Weather App)
  - Task: Rebuild Rock Paper Scissors & Image Slider; swap Weather App for a different API

### React — 3 Weeks
- [ ] **Week 1:** Fundamentals & First Project (JSX → Chatbot features)
  - Task: Finish Chatbot Project, extend it with a new feature
- [ ] **Week 2:** Tooling & Routing (Hooks → start Ecommerce Project)
  - Task: Migrate a project to Vite + Git, get 3-page routing working on Ecommerce Project
- [ ] **Week 3:** Data, Testing & Deployment (Data Fetching → AI with React)
  - Task: Finish Ecommerce Project (fetch + mutate), write Vitest tests, deploy to AWS
